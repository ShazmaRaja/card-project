# The Greatest PS4 Collection

A simple responsive game showcase gallery built with HTML and CSS, featuring a set of PS4 titles and a personal favorite pick.

## Overview

The page displays a grid of game cards (God of War, Call of Duty, GTA V, The Last of Us, FIFA, Resident Evil) along with a highlighted favorite section for Red Dead Redemption 2.

The layout is responsive, adjusting from a 3-column grid on desktop to 2 columns on tablet and 1 column on mobile.

## Built With

- HTML5
- CSS3 (Grid, media queries)

## Getting Started

No build tools required, this is a static site.

1. Clone the repo:
   ```bash
   git clone https://github.com/ShazmaRaja/card-project.git
   ```
2. Open `index.html` in your browser.
